# Random Task Generator
**Автор:** Алтухов Роман Сергеевич
GUI-приложение на Python (Tkinter), которое генерирует случайные задачи, ведёт историю, позволяет фильтровать задачи по типу (учёба/спорт/работа) и сохраняет историю в JSON.
## Возможности
- Предопределённые задачи
- Кнопка «Сгенерировать задачу» (случайный выбор с учётом фильтра)
- История сгенерированных задач (список)
- Фильтрация по типу задачи: учёба, спорт, работа
- Добавление новых задач (валидация: не пустая строка)
- Сохранение/загрузка истории в `tasks_history.json`
## Запуск
1. Установите Python 3.10+ (рекомендуется).
2. В папке проекта выполните:
   ```bash
   python app.py
