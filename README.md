Примеры использования (мини-тесты)
Выберите фильтр спорт → нажмите «Сгенерировать задачу» → в истории появляются только задачи типа спорт.
Добавьте задачу с пустым названием → приложение показывает ошибку и не добавляет задачу.
Нажмите «Сохранить историю (JSON)» → перезапустите приложение → история загружается автоматически.
